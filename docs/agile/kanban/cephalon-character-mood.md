## Context

The recovered mood tool returns an action-shaped result; the donor field uses
keyword counters. Neither establishes the operator's separate evolving mood
model. Eidolon/Nooi and Duck's feedback notes connect changing conditions to
attention, association and expression.

## Outcome

One persisted, versioned mood model changes on encounters, outcomes and elapsed
time. Its state causally changes attention and recalled associations, and is
shared by the character's facets without becoming identity or a permission grant.

## Scope

Knoxx composes explicit mood state and invocation budgets with the reviewed
physical graph/field seam. A dedicated appraisal invocation may interpret an
encounter; validated pure transitions own updates. A separate model contract,
state and trace are mandatory. Whether distinct model weights improve appraisal
is measured; no paid/new provider is required by the plan.

## Non-goals

Claim subjective feelings, reduce affect to a changing prompt adjective, infer
mood solely from keyword frequency, rewrite personality per turn, or place
expensive appraisal on the responsive head's acknowledgment path.

## Acceptance criteria

1. The mood contract names dimensions, ranges, uncertainty, baseline/decay,
   event/appraisal inputs and transition revision. Map any diagnostic coordinates
   explicitly to the recovered field model; do not silently replace its axes.
2. An admitted encounter changes the model with prior/new state, causal IDs,
   elapsed time, appraisal/model/config identity and sampling seed retained.
   Duplicate events cannot apply twice; timestamp disorder has explicit behavior.
3. Quiet time changes decay without requiring a message. Contradictory,
   malformed, missing and late appraisals cannot fabricate facts or valid updates.
   Appraisal failure leaves an observable outcome and an explicit fallback policy.
4. Paired identical-seed cases with different mood states change bounded
   attention/graph recall and expression, with the influenced decision recorded.
   A state counter or telemetry-only result cannot satisfy this criterion.
5. Concurrent facets update through the existing persistent-state authority with
   a revision check; conflict retries cannot lose or duplicate admitted changes.
   Restart/replay restores mood and its trace.
6. Appraisal cadence, tokens, queue, timeout and retries are bounded and
   independent of maker execution; mood cannot expand tool/account permissions.

## Verification

Red transition/replay laws, invalid provider output fixtures and concurrent
revision conflicts precede domain/adapters. A controlled fixed-seed integration
case proves mood -> attention -> included recall -> choice. Observe real
appraisal use only after qualified deployment and report its actual cost/latency.

## Risks

Invented emotional narratives, model-dependent appraisals, drift in coordinate
meaning, conflicting facet updates and feedback loops driven by self-output.
